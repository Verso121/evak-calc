# Эвак Калькулятор

Быстрый расчёт стоимости эвакуации для клиента: выбор авто из базы (~700 моделей), категория
(легковой, кроссовер, мото, коммерческий, автобус, грузовик и спецтехника до 5 т), гружёный/пустой
и габариты, маршрут A → B на карте, условия (кювет, колёса, ночь и т.д.).

- Тарифы настраиваются в приложении (⚙︎) и хранятся на устройстве; перенос между устройствами — Экспорт/Импорт.
- Карта и маршруты — OpenStreetMap / OSRM, ключи не нужны.
- Устанавливается на телефон и ПК как приложение (PWA).
